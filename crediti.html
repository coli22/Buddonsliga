Calcolo Crediti Svincolo

Inserisci i dati del giocatore e calcola automaticamente i crediti recuperati, con la formula esatta dal regolamento.

Svincolo normale: Se hai pagato ≥ quotazione attuale, recuperi la quota attuale. Se hai pagato meno, recuperi il prezzo pagato più la variazione rispetto alla quota iniziale.
Come trovare la quotazione: Apri Fantacalcio app → cerca il giocatore. Se il trasferimento avviene durante una giornata di campionato, usa la quotazione della giornata precedente.

    📋 Riepilogo Regole
    • ⚽ Normale (pagato ≥ QA): C = QA
    • ⚽ Normale (pagato < QA): C = A + (QA − QB) · min 1 credito
    • 🌍 Estero (pagato ≥ QA): C = max(A÷2, QA)
    • 🌍 Estero (pagato < QA): C = A + (QA − QB) · formula normale
    • 🤕 Infortunio 3-6 mesi: C = max(QA infortunio, A×50%)
    • 🤕 Infortunio >6 mesi: C = max(QA infortunio, A×60%)
    • 💀 Morte: max formula normale; se ≥30 puoi prendere uno svincolato
